How to use this: drop in the .docx your associate emailed → check the 21 boxes below and fix anything that landed in the wrong place → Download calendar-data.json → copy that file onto the drive → on the display PC, drop it into the Child Life Calendar folder next to Child Life Calendar.html, replacing the old one → refresh or reboot the display. The display imports it once and then leaves it alone, so anything you edit on the display PC afterwards stays put.
